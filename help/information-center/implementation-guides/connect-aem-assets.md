# Connexion d’Adobe Commerce à AEM Assets pour la gestion des ressources

AEM Assets peut être connecté à Adobe Commerce par le biais de différents chemins d’intégration, en fonction du produit Commerce.

Pour Adobe Commerce sur les infrastructures cloud, utilisez l’intégration AEM Assets pour Commerce. Pour Adobe Commerce as a Cloud Service et Adobe Commerce Optimizer, utilisez des visuels de produit optimisés par AEM Assets.

>[!NOTE]
>
>Ce guide couvre les chemins d’intégration AEM Assets pour Adobe Commerce sur les infrastructures cloud, Adobe Commerce as a Cloud Service et Adobe Commerce Optimizer. Suivez le chemin d’accès correspondant à votre produit et à votre déploiement .

## Prise en main

1. Consultez la documentation [Intégration AEM Assets pour Commerce](/help/aem-assets-integration/overview.md) pour connaître les conditions préalables et la configuration.


1. Pour activer la gestion des ressources avec AEM Assets, suivez les instructions [Étapes suivantes](/help/aem-assets-integration/overview.md#next-steps) correspondant à votre type de déploiement dans le _[Guide d’intégration d’AEM Assets pour Commerce](/help/aem-assets-integration/overview.md)_.
