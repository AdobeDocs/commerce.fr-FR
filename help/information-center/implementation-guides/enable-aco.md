# Activer Adobe Commerce Optimizer

[!DNL Adobe Commerce Optimizer] est une couche de merchandising et de découverte de produits composable qui se connecte au cloud Adobe Commerce ou sur site via [!DNL Adobe Commerce Optimizer Connector] et alimente les storefronts créés sur Edge Delivery Services. Il n’est actuellement pas disponible avec Adobe Commerce as a Cloud Service.

## Prise en main

1. Revue [Qu’est-ce que Adobe Commerce Optimizer ?](/help/optimizer/overview.md) pour comprendre ce qu’il apporte.

1. Pour connaître les étapes de configuration dans Adobe Commerce Optimizer, voir [Prise en main](/help/optimizer/get-started.md).

1. Pour les déploiements sur le cloud ou on-premise de Commerce, suivez la documentation [[!DNL Adobe Commerce Optimizer Connector]](/help/aco-connector/overview.md) pour exporter les données de catalogue, synchroniser les prix et connecter votre storefront.
